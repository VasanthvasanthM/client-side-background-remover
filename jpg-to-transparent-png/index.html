Why the output is a PNG

JPG simply has no way to record that a pixel is transparent. This is the single reason "make my JPG background transparent" always ends in a different file type — there is nowhere in a JPG to put the information.

How to do it

  • Drop your JPG file onto the page, or paste it from the clipboard.
  • The background is detected automatically; adjust the tolerance if anything is left behind.
  • Use the eyedropper or the brush for anything the automatic pass missed.
  • Choose PNG and download. The transparency is in the file, not faked with white.

Common questions

Can a JPG file have a transparent background?

No. JPG has no alpha channel at all, so transparency cannot be stored in it. Whatever you remove would come back as white or black. Saving as PNG is the only way to keep it.

Will the quality drop when I convert?

Not from the conversion. PNG is lossless, so the pixels it keeps are exactly the ones it was given. Any compression artefacts already in the JPG stay as they are — converting cannot undo them, but it does not add more.

Is my JPG file uploaded?

No. The browser decodes it locally and the processing runs on your own machine. There is no server in this, which also means no queue and no file size limit beyond what your device can hold.
